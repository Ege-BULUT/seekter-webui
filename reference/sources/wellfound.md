# Wellfound

Startup board (`wellfound.com/role/r/<role-slug>`). Measured for one discipline; discovery only.

- **Browsable logged out**, but **Apply needs an account**, so it is a discovery source: find the role here, apply on the employer's own site.
- Its **"Remote only • Everywhere"** tag is the most useful thing on the board: it is an explicit worldwide-remote marker, which most boards do not give you. Still verify against the posting's own eligibility line, per the country-list rule.
- **Postings run 1-4 months old.** Treat anything here as possibly filled and resolve the employer's own careers page before investing in a form.
- Cadence: monthly. It has never been the source that found the day's applications.
